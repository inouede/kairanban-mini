# スマート回覧板 - プッシュ通知対応版 v6.0

## 🎉 FTPアップロードだけで動作！

このバージョンは、**FTPでアップロードするだけで完全に動作します。**

- ✅ Composerインストール不要
- ✅ VAPID鍵の手動生成不要（自動生成）
- ✅ 下層フォルダ対応（ルートディレクトリ不要）
- ✅ 追加設定一切不要

---

## 📦 セットアップ手順

### 1. FTPでアップロード

このフォルダ全体を、サーバーの任意のディレクトリにアップロードするだけです。

```
例: https://example.com/kairanban/
または: https://example.com/
```

**どちらでもOK！** 下層フォルダでも動作します。

### 2. パーミッション設定

```bash
chmod 777 data/
```

### 3. 完了！

ブラウザでアクセスするだけで動作します。

**初回アクセス時に自動的に:**
- VAPID鍵が生成される
- `data/vapid.json` に保存される

---

## 🎯 使い方

### 通知を有効にする

1. ログイン
2. 右上のプロフィールアイコンをクリック
3. **「通知を許可」** をクリック（ログアウトの上にある黒いボタン）
4. ブラウザの通知ダイアログで「許可」をクリック
5. ✅ プッシュ通知が有効になる

### ボタンの動作

「通知を許可」ボタンをクリックすると:

1. 通知許可をリクエスト
2. 既存の通知設定を一旦解除
3. 新しい通知設定で再登録
4. サーバーに送信

→ **通知を許可していようがしていまいが、1クリックで確実に通知を許可**

## 🔧 技術的な詳細

### Web Push実装

- **ライブラリ:** なし（PHPの標準関数のみ）
- **暗号化:** AES-128-GCM
- **認証:** VAPID (ES256)
- **プロトコル:** RFC 8291, RFC 8292

### VAPID鍵

- **生成:** OpenSSL（楕円曲線暗号 prime256v1）
- **保存:** `data/vapid.json`
- **取得:** `api/vapid-public-key.php`

### Service Worker

- **パス:** 相対パス `./sw.js`
- **スコープ:** 自動検出
- **キャッシュ:** なし（ネットワーク優先）

## 🐛 トラブルシューティング

### プッシュ通知が届かない

**確認事項:**

1. HTTPSで接続しているか
2. `data/` のパーミッションが777か
3. ブラウザで通知が許可されているか
4. Service Workerが登録されているか

**解決策:**

1. プロフィール → 「通知を許可」をクリック
2. ブラウザのキャッシュをクリア
3. F12 → Console でエラーを確認

### プロフィールメニューにボタンが表示されない

**原因:** index.htmlが更新されていない

**解決策:**

1. 新しいindex.htmlで上書き
2. ブラウザキャッシュをクリア（Ctrl+Shift+R）
